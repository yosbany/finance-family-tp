================================================================================
                           SECURITY ARCHITECTURE
================================================================================

REQUEST FLOW:
  
  1. User authenticates → Firebase Auth (frontend)
  2. Obtain ID Token → getIdToken() 
  3. Frontend calls → callSearchTransactions(params)
  4. HTTP POST → https://...functions.net/searchTransactionsEndpoint
     Header: Authorization: Bearer <idToken>
     Body: { from, to, accountId, ... }
  5. Cloud Function receives
     ├─ Verifies token with admin.auth().verifyIdToken()
     ├─ Extracts uid from verified token
     ├─ Creates AuthenticatedContext { uid }
     └─ IMPOSSIBLE to override uid from params
  6. Tool execution
     ├─ Validates input (rejects prohibited params)
     ├─ Gets family root from uid
     ├─ Reads transactios from ${familyRoot}/transactions
     ├─ Applies filters
     └─ Returns sanitized results
  7. Response
     ├─ Status 200 OK
     ├─ transactions: [...]
     ├─ pagination metadata
     └─ NO uid, paths, credentials, internal fields

SECURITY GUARANTEES:

  ✅ Authenticity    - Token verified by Firebase Admin SDK
  ✅ Integrity       - No uid spoofing possible
  ✅ Confidentiality  - UID-scoped data access
  ✅ Availability    - Rate limiting ready (FASE 05+)
  ✅ Non-repudiation - All ops logged to Firebase
