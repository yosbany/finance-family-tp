                          2. CONTRATO TÉCNICO
================================================================================

INPUT:
  {
    from: number                      [requerido, timestamp ms]
    to: number                        [requerido, timestamp ms]
    currency?: 'UYU' | 'USD'         [opcional]
    accountId?: string               [opcional]
    categoryId?: string              [opcional]
  }

OUTPUT (single currency):
  {
    period: { from, to },
    summary: {
      currency: 'UYU' | 'USD',
      income: number,
      expenses: number,
      net: number,
      transfers: number,
      transactionCount: number,
      incomeCount: number,
      expenseCount: number,
      transferCount: number,
      savingsRate?: number            [undefined si income == 0]
    }
  }

OUTPUT (multi-currency):
  {
    period: { from, to },
    byCurrency: [
      { currency: 'UYU', income, expenses, net, ... },
      { currency: 'USD', income, expenses, net, ... }
    ]
  }

================================================================================
                          3. REGLAS FINANCIERAS
================================================================================

INCOME:
  sum(type='income' transactions)
  incomeCount = count(type='income')

EXPENSES:
  sum(abs(type='expense' transactions))
  expenseCount = count(type='expense')

TRANSFERS:
  sum(abs(type='transfer' transactions))  [tracked separately]
  transferCount = count(type='transfer')
  
  IMPORTANTE:
  - NO cuentan como income ni expense
  - NO se incluyen en net
  - net = income - expenses [sin transfers]

NET:
  net = income - expenses
  [NUNCA incluye transfers]

SAVINGS RATE:
  savingsRate = ((income - expenses) / income) * 100
  [undefined si income == 0]
  [puede ser negativo si expenses > income]

MULTI-CURRENCY:
  - Si currency especificado: retorna resumen en esa moneda
  - Si NO especificado:
    * Una moneda → summary (objeto)
    * Varias monedas → byCurrency (array separado)
  - NO hay conversión en esta fase

================================================================================
                          9. MATRIZ DE DECISIONES
================================================================================

¿Qué pasa si...?

Q: El usuario pregunta "Cuánto gasté"
A: LLM elige getFinancialSummary → respuesta rápida, determinística

Q: El usuario pregunta "Mostrame mis últimas 10 transacciones"
A: LLM elige searchTransactions → detalle completo

Q: Hay >500 transacciones en el período
A: getFinancialSummary retorna error → usuario debe usar filtros en searchTransactions

Q: Hay múltiples monedas
A: Si no especifica currency → retorna byCurrency (array separado)

Q: Income es 0
A: savingsRate = undefined (no dividir por cero)

Q: El usuario envía uid=otro-usuario
A: Validador rechaza → error SECURITY_VIOLATION
