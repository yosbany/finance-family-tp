1 NEW TOOL: getFinancialSummary

   Input:
   {
     from: number              (timestamp ms, required)
     to: number                (timestamp ms, required)
     currency?: 'UYU' | 'USD'
     accountId?: string
     categoryId?: string
   }

   Output:
   {
     period: { from, to },
     summary: {
       currency: string,
       income: number,
       expenses: number,
       net: number,
       transfers: number,
       transactionCount: number,
       incomeCount: number,
       expenseCount: number,
       transferCount: number,
       savingsRate?: number
     }
     // OR byCurrency: [ ] if multiple currencies
   }

================================================================================
                     KEY FINANCIAL RULES
================================================================================

income    = sum(type='income' txs)
expenses  = sum(abs(type='expense' txs))
transfers = sum(abs(type='transfer' txs))  [tracked separately]
net       = income - expenses              [transfers NOT included]
savingsRate = ((income - expenses) / income) * 100 [undefined if income==0]

Multi-currency: SEPARATED, never merged (no USD + UYU sum)

✅ Rejects: uid, userId, familyId, firebasePath, path
✅ Identity: From Firebase ID Token via AuthenticatedContext
✅ Privacy: LLM gets totals only, never individual transactions
✅ Validation: All inputs checked server-side
