DEPLOYMENT FLOW (STEP-BY-STEP)
═══════════════════════════════════════════════════════════════════════════════

PHASE 1: PREPARE FIREBASE CREDENTIALS
─────────────────────────────────────
1. Go to Firebase Console → finance-family-tp
2. Settings → Service Accounts → Generate New Private Key
3. Save as firebase-service-account.json
4. Read FIREBASE_SETUP.md for security requirements
5. Keep file in safe location locally (NOT in git)

PHASE 2: PREPARE LOCAL MACHINE
──────────────────────────────
1. cd /Users/yosbanytejas/Documents/finance-family
2. bash deployment/00-prepare-local.sh
3. Verify: ls -lh deployment/finance-family-backend.tar.gz
4. Should be ~25M

PHASE 3: UPLOAD TO VPS
──────────────────────
1. scp deployment/finance-family-backend.tar.gz root@179.43.124.107:/tmp/
2. scp deployment/01-deploy.sh root@179.43.124.107:/tmp/
3. scp deployment/service.nrdonline.site.nginx root@179.43.124.107:/tmp/
4. scp deployment/03-verify-firebase.sh root@179.43.124.107:/tmp/
5. scp deployment/04-operations.sh root@179.43.124.107:/tmp/
6. scp /path/to/firebase-service-account.json root@179.43.124.107:/tmp/

PHASE 4: DEPLOY ON VPS
──────────────────────
1. ssh root@179.43.124.107
2. sudo bash /tmp/01-deploy.sh /tmp/finance-family-backend.tar.gz
3. Wait for completion (creates user, directories, service)
4. sudo cp /tmp/firebase-service-account.json /etc/finance-family-api/
5. sudo chown root:root /etc/finance-family-api/firebase-service-account.json
6. sudo chmod 600 /etc/finance-family-api/firebase-service-account.json

PHASE 5: VERIFY FIREBASE
────────────────────────
1. sudo bash /tmp/03-verify-firebase.sh
2. Should show:
   - Credentials file exists
   - Valid JSON
   - Project ID: finance-family-tp
   - Type: service_account

PHASE 6: START SERVICE
──────────────────────
1. sudo systemctl enable finance-family-api
2. sudo systemctl start finance-family-api
3. sudo systemctl status finance-family-api
4. curl http://127.0.0.1:8030/health
5. Should return HTTP 200

PHASE 7: CONFIGURE NGINX
────────────────────────
1. sudo cp /tmp/service.nrdonline.site.nginx \
   /etc/nginx/sites-available/service.nrdonline.site
2. sudo ln -sf /etc/nginx/sites-available/service.nrdonline.site \
   /etc/nginx/sites-enabled/
3. sudo nginx -t
4. If valid: sudo systemctl reload nginx

PHASE 8: TEST HTTPS
───────────────────
1. curl https://service.nrdonline.site/health
2. Should return HTTP 200
3. If cert not found, run certbot:
   sudo certbot certonly --webroot -w /var/www/letsencrypt \
   -d service.nrdonline.site

PHASE 9: RUN TEST SUITE
───────────────────────
1. From local machine:
   bash deployment/02-test-deployment.sh https://service.nrdonline.site
2. All tests should pass ✅

PHASE 10: END-TO-END TEST
─────────────────────────
1. Frontend: https://yosbany.github.io
2. Login with Firebase
3. Get ID token
4. Call API:
   curl -X POST https://service.nrdonline.site/api/tools/search-transactions \
   -H "Authorization: Bearer <ID_TOKEN>" \
   -H "Content-Type: application/json" \
   -d '{"limit": 10}'
5. Should return transactions (if any) or empty array

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════
Service won't start:
  1. Check logs: sudo journalctl -u finance-family-api -n 100
  2. Check Firebase credentials: sudo jq . /etc/finance-family-api/firebase-service-account.json
  3. Verify environment file: cat /etc/finance-family-api/finance-family-api.env

Health check returns 500:
  1. Check Firebase connection: sudo journalctl -u finance-family-api | grep -i firebase
  2. Verify port 8030: sudo netstat -tlnp | grep 8030
  3. Check service user permissions: ls -la /opt/finance-family-api

Nginx 502 Bad Gateway:
  1. Verify backend running: sudo systemctl status finance-family-api
  2. Check port 8030 listening: sudo netstat -tlnp | grep 8030
  3. Test local endpoint: curl http://127.0.0.1:8030/health
  4. Check Nginx error log: sudo tail -f /var/log/nginx/error.log
