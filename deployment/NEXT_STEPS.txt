STEP 6️⃣  CONFIGURE NGINX
────────────────────────

On VPS:

Copy Nginx configuration:
  sudo cp /tmp/service.nrdonline.site.nginx \
    /etc/nginx/sites-available/service.nrdonline.site

Create symlink:
  sudo ln -sf /etc/nginx/sites-available/service.nrdonline.site \
    /etc/nginx/sites-enabled/

Test Nginx configuration:
  sudo nginx -t

Should show: "successful" and "syntax is ok"

Reload Nginx:
  sudo systemctl reload nginx

STEP 9️⃣  END-TO-END TEST (Manual)
─────────────────────────────────

1. Open frontend: https://yosbany.github.io

2. Click "Login with Firebase" (or similar)

3. Authenticate with Firebase

4. After login, open browser console (F12 → Console)

5. Get the ID token:

6. Copy the token

7. Test the API (from console or Postman):
   curl -X POST https://service.nrdonline.site/api/tools/search-transactions \
     -H "Authorization: Bearer YOUR_TOKEN_HERE" \
     -H "Content-Type: application/json" \
     -d '{"limit": 10}'

Expected responses:
  • HTTP 200 with transactions array (may be empty if no data)
  • Or HTTP 400 if parameters invalid

TROUBLESHOOTING QUICK REFERENCE:
─────────────────────────────────────────────────────────────────────────────

Service won't start:
  sudo journalctl -u finance-family-api -n 100
  # Look for Firebase initialization errors

Health check returns 500:
  sudo journalctl -u finance-family-api | grep -i error
  # Check Firebase credentials

Nginx 502 Bad Gateway:
  curl http://127.0.0.1:8030/health  # Test internal endpoint
  sudo netstat -tlnp | grep 8030     # Verify port binding
  sudo systemctl status finance-api   # Check service status

CORS errors:
  sudo cat /etc/finance-family-api/finance-family-api.env | grep ALLOWED
  # Verify ALLOWED_ORIGINS is set to HTTPS origin
