   Output: {transactions: [...], pagination: {...}}
   Security: UID from token, not request body

=====================================
5. SEGURIDAD
=====================================

✅ Authentication
   - Firebase ID Token verified on every request
   - Invalid tokens rejected with 401

✅ Authorization
   - UID extracted ONLY from verified token
   - NEVER accepted from request body

✅ Input Validation
   - All parameters validated server-side
   - Prohibited params rejected: uid, firebasePath, path, etc.
   - Unknown parameters rejected
   - Type checking, range checking, enum validation

✅ Output Sanitization
   - No full objects returned
   - No internal paths, credentials, stack traces
   - Only necessary data

✅ Error Handling
   - Centralized error handler
   - No sensitive details exposed
   - Standard JSON error responses

✅ Logging
   - Logs: timestamps, paths, status codes, duration
   - NOT logged: tokens, credentials, PII, full data

10. DEPLOYMENT WORKFLOW
=====================================

Una vez tengas acceso VPS:

Fase 1: Inspeccionar VPS
   - OS, Docker, servicios existentes
   - Puertos en uso
   - Reverse proxy instalado

Fase 2: Verificar DNS
   - nslookup service.nrdonline.site
   - Debe apuntar a IP del VPS

Fase 3: Configurar Secretos
   - Copiar service-account.json a /etc/finance-family/secrets/
   - Permisos: 600, propietario: nodeapp

Fase 4: Desplegar Backend
   Opción A: Docker Compose
   - docker-compose build
   - docker-compose up -d

   Opción B: Manual
   - npm install --production
   - npm run build
   - systemd service

Fase 5: Configurar Reverse Proxy
   - Nginx vhost para service.nrdonline.site
   - Proxy a 127.0.0.1:3001
   - Rate limiting
   - Security headers

Fase 6: SSL/TLS
   - Let's Encrypt certificate
   - certbot para renovación automática

Fase 7: Verificar
   - curl https://service.nrdonline.site/health
   - curl -X POST con token válido
   - Monitorear logs

Fase 8: Frontend
   - Actualizar VITE_FINANCE_API_URL=https://service.nrdonline.site
   - npm run build
   - Desplegar a GitHub Pages
